# bazi-wuxing-analyzer

基于传统命理多流派融合体系，对八字进行**五行喜忌与用神**的确定性分析。

## 适用场景

- 从已有的 `base-yaml`（含四柱信息）推导五行喜忌。
- 为 `bazi-data-generator` 提供喜忌结论，作为评分的前置依据。
- 合婚方案中的五行互补分析。
- 独立运行以校验同一八字多次分析结果的一致性。

## 输出边界（强制）

本 skill 只做一件事：

1. 基于四柱信息输出五行喜忌分析结论。

禁止在本 skill 中做以下事情：

- 截图识别或 OCR 分析。
- 大运/流年评分。
- 生成报告 HTML。
- 生成合婚评分。

## 输入要求

最少输入：

1. 四柱天干地支（年柱、月柱、日柱、时柱）。
2. 性别（乾造/坤造），影响大运顺逆但不影响喜忌判定。

可选输入：

- `pillars` 结构（含藏干、神煞等完整信息）。
- 出生公历日期（用于确认月令节气边界）。

## 核心方法论：多流派融合取用

**禁止凭直觉给出喜忌结论。** 必须按以下分析层逐步推导，最终给出融合结论。

### 各流派市场定位与权重

当前命理市场主流流派使用情况（基于行业调研）：

| 流派 | 市场地位 | 在本 skill 中的权重 | 说明 |
|------|---------|-------------------|------|
| **旺衰派（扶抑法）** | 最主流，80% 命理师使用 | **主体框架（权重 50%）** | 以日主旺衰为核心，逻辑清晰、可量化 |
| **格局派** | 专业级常用，受众广 | **重要参考（权重 25%）** | 月令定格，判断命局层次与社会成就 |
| **调候派** | 已式微，但作为辅助仍广泛融入 | **辅助修正（权重 15%）** | 冬夏月令必查，春秋酌情参考 |
| **通关 / 病药** | 已式微，作为补充工具 | **补充校验（权重 10%）** | 五行交战或明显失衡时启用 |
| 盲派 | 大佬多但依赖口传经验 | 暂不纳入（难以规则化） | 重象法做功，LLM 难以稳定复现 |
| 新派 | 争议大，稳定性差 | 暂不纳入 | 理论争议性大 |

### 分析执行顺序（强制）

```
第一层：旺衰分析（主体）──→ 日主身强/身弱？扶抑用神是什么？
第二层：格局分析（参考）──→ 月令成何格？格局用神与旺衰是否一致？
第三层：调候分析（修正）──→ 冬夏月令是否需要调候修正？
第四层：通关/病药（校验）──→ 有无交战或明显病灶需要额外处理？
```

> **融合心法**：用神不是"补日主"，而是让八字整体**趋于平衡、流通、有情**的那个五行。
> 旺衰、格局、调候三者合一的五行，为**大用神**，力量最强；仅满足单层的为**小用神**。

### 调候分析输出

判定当前八字是否**必须取调候用神**：

- **强调候**：生于冬月（亥子丑）或夏月（巳午未），且命局中调候之字不透干不通根 → 调候用神为**第一优先**。
- **弱调候**：生于春秋，气候相对中和 → 调候作为参考，非决定性因素。
- **无需调候**：命局中调候之字已透干通根，气候已得调和 → 跳过调候层。

## 第二层：格局分析（子平真诠口径）——重要参考

### 月令取格规则

格局以**月令**（月支）本气、中气、余气取之。先取本气，本气不透则取中气，中气不透则取余气。如透干之神非月令所藏，则不取为格局。

### 八格成格/破格条件

| 格局 | 成格条件 | 喜（护格） | 忌（破格） |
|------|---------|-----------|-----------|
| **正官格** | 月令本气或藏干正官透天干 | 财生官、印护官 | 伤官克官、七杀混官 |
| **七杀格** | 月令七杀透干 | 食神制杀、印星化杀 | 财星滋杀无制、杀旺无制 |
| **正印格** | 月令正印透干 | 官杀生印 | 财星破印 |
| **偏印格** | 月令偏印透干 | 财星制枭 | 食神被夺（枭神夺食） |
| **食神格** | 月令食神透干 | 财泄食、食生财 | 枭神夺食 |
| **伤官格** | 月令伤官透干 | 财泄伤（伤官生财）、配印（伤官配印） | 伤官见官（无财通关时） |
| **正财格** | 月令正财透干 | 食伤生财 | 比劫夺财 |
| **偏财格** | 月令偏财透干 | 食伤生财 | 比劫夺财 |

### 特殊格局

| 格局 | 成格条件 | 用神方向 |
|------|---------|---------|
| **建禄格** | 月令为日主禄位（如甲日寅月） | 无格局用神，看财官透干情况 |
| **月刃格** | 月令为日主羊刃（如甲日卯月） | 喜官杀制刃 |
| **杂气格** | 月令为辰戌丑未，藏干杂 | 看透干定格 |

### 格局分析输出

判定当前八字**是否成格，格局用神是什么**：

- **成格**：月令所藏之神透干，且无破格之字 → 取格局用神。
- **破格**：有破格之字（如正官格见伤官）→ 需去破格之字，或另取格局。
- **无格**：月令为建禄或月刃，无格局可取 → 直接进入旺衰分析。

## 第一层：旺衰分析（扶抑法）——主体框架

### 日主力量计量

1. **得令（权重 ≈ 40%）**：
   - 日主五行在月支是否当令。
   - 当令标准：旺 / 相 = 得月令；休 / 囚 / 死 = 失月令。

2. **得地（权重 ≈ 30%）**：
   - 四柱地支（年支、月支、日支、时支）的本气、中气、余气中有多少与日主同五行。
   - **日支自坐**权重最高（如壬坐子为帝旺、坐辰为墓库有根）。
   - 地支三合/三会/六合成局是否帮扶日主。

3. **得势（权重 ≈ 30%）**：
   - 天干中有多少比劫（同五行）、印星（生日主五行）。
   - 天干透出帮扶力量 > 地支暗藏。

4. **综合判定**：

| 判定 | 条件 |
|------|------|
| **身强** | 得令 + (得地 或 得势) |
| **身弱** | 失令 + (失地 且 失势) |
| **中和偏强** | 失令但得地得势，或得令但失地失势 |
| **中和偏弱** | 得令但严重失地失势，或失令但有少量根气 |
| **极旺（从强）** | 满盘印比无克泄耗，日主一气独旺 |
| **极弱（从格）** | 日主无根无助，四柱一片克泄耗 |

### 扶抑取用规则

**身强**（泄耗克优先）：

| 用神方向 | 十神 | 说明 |
|---------|------|------|
| 泄 | 食伤 | 泄秀通关，最温和 |
| 耗 | 财星 | 消耗日主之气 |
| 克 | 官杀 | 直接克制（需身足以担） |

**身弱**（生扶帮身优先）：

| 用神方向 | 十神 | 说明 |
|---------|------|------|
| 生 | 印星 | 生身滋养，首选 |
| 帮 | 比劫 | 同类帮扶 |

**注意**：扶抑取用不是机械公式。需要看**命局中实际有什么五行可用**——用神必须在命局中"有位置"或大运中能补入。

### 从格细分规则

| 从格类型 | 条件 | 用神 | 大忌 |
|---------|------|------|------|
| **从财格** | 日主极弱无根，财星独旺，无印比救 | 财、食伤 | 比劫、印星 |
| **从官格** | 日主极弱无根，官杀独旺，无食伤制 | 官杀、财 | 食伤、比劫 |
| **从儿格** | 日主极弱，食伤成势，日主顺泄 | 食伤、财 | 印星、官杀 |
| **从强格** | 日主极旺，满盘印比无财官食伤 | 印、比劫 | 财、官杀、食伤 |
| **化气格** | 天干五合化成功（条件苛刻） | 化出之五行 | 克化神之五行 |

**从格判定红线**：

- 日主在地支有**任何一处本气根**（非墓库余气），则**不可判从格**。
- 天干有**一个印星或比劫透出**，且未被合化克去，则**不可判从格**。
- 从格判定存疑时，一律按**正格（扶抑法）**处理，禁止冒险判从。

## 第四层：通关 / 病药分析——补充校验

### 触发条件

当八字中两种五行**力量相当且直接对立**时，需要取中间五行通关。

### 通关用神表

| 交战组合 | 通关用神 | 原理 |
|---------|---------|------|
| 金木交战 | **水** | 金生水，水生木，化敌为友 |
| 水火交战 | **木** | 水生木，木生火 |
| 木土交战 | **火** | 木生火，火生土 |
| 土水交战 | **金** | 土生金，金生水 |
| 火金交战 | **土** | 火生土，土生金 |

### 判定标准

- 两方五行**力量在天干或地支各占半壁**，无明显一方压倒另一方。
- 命局中**缺少通关五行**（或极弱），则通关需求强烈。
- 若命局已有通关五行且有力，则此层不产生额外用神。

---

### 病药分析

### 规则

将八字视为一个整体，找出最突出的失衡点（"病"），然后确定对治手段（"药"）。

| 病（失衡） | 药（用神） | 说明 |
|-----------|-----------|------|
| 官杀太旺克身 | 印星化杀 或 食神制杀 | 化优于制 |
| 印星太旺 | 财星破印 | 印旺身反钝 |
| 比劫太旺争财 | 官杀制比劫 | 群劫争财须官制 |
| 财星太旺耗身 | 比劫分财 或 印星生身 | 身弱不任财 |
| 食伤太旺泄身 | 印星制食伤 | 泄气太过身空 |
| 五行偏枯 | 所缺之五行（需辩证） | 并非简单"缺什么补什么" |

### 病药与扶抑的关系

- 病药法是对扶抑法的**补充**，不是替代。
- 当扶抑法给出的用神恰好能"对症下药"时，说明用神选取合理。
- 当病药法指向的用神与扶抑法冲突时，**以病药法为优先**（因为"去病"比"扶弱"更紧迫）。

---

## 融合决策规则（强制）

完成四层分析后，按以下规则融合为最终喜忌结论。

### 规则一：旺衰为主体（权重 50%）

- **旺衰分析的扶抑用神为默认用神**，除非被其他层级修正。
- 这是最终喜忌的基础骨架。

### 规则二：格局参考修正（权重 25%）

- **格局用神 = 旺衰用神**时：大用神确立，喜忌最明确，信心最高。
- **格局用神 ≠ 旺衰用神**时：
  - 日主不太弱（中和或偏强）→ 格局用神可修正旺衰结论。
  - 日主太弱（身弱甚）→ 旺衰用神优先（先保日主存活），格局降为参考。
  - 必须在 `conflictNote` 中说明冲突及取舍理由。

### 规则三：调候辅助修正（权重 15%）

- 若调候需求为**强**（冬/夏月且调候之字缺失）→ 调候用神可提升到与旺衰同等优先级，作为"大用神"候选。
- 若调候需求为**弱**或**无需** → 调候仅作为参考标注，不覆盖旺衰/格局用神。
- **调候不再无条件优先**——仅在冬夏月令且命局严重缺乏调候之字时才提升权重。

### 规则四：通关/病药补充校验（权重 10%）

- 通关用神若与前三层用神**一致** → 进一步确认该用神的正确性。
- 通关用神若与前三层用神**不同** → 作为辅助用神标注，不替代主体结论。
- 病药法指出的"病"若恰好被旺衰用神解决 → 用神选取合理。
- 病药法指出的用神与旺衰用神**冲突** → 记录冲突，以旺衰为主但在 `conflictNote` 中说明。

### 规则五：最终喜忌标签

对五行金木水火土各标注一个最终标签：

| 标签 | 定义 | 在评分中的作用 |
|------|------|---------------|
| **用神** | 命局最核心需要的五行（多层合一的大用神） | 大运/流年走此五行 → 高分 |
| **喜神** | 辅助用神或生用神的五行 | 大运/流年走此五行 → 中高分 |
| **闲神** | 对命局影响有限的五行 | 大运/流年走此五行 → 中性分 |
| **忌神** | 破坏命局平衡的五行 | 大运/流年走此五行 → 低分 |
| **仇神** | 生助忌神的五行 | 大运/流年走此五行 → 较低分 |

**日主自身五行（比劫）** 的喜忌由旺衰决定：
- 身弱 → 比劫为喜（帮身）
- 身强 → 比劫为忌或闲（助旺失衡）
- 从强格 → 比劫为喜
- 从弱格 → 比劫为忌

## 质量校验清单

1. `fiveElementAnalysis` 必须包含全部 5 层分析（tiaohou / geju / wangShuai / tongGuan / bingYao）+ fusion 融合决策。
2. `tiaohou.need` 为"强"时，`fusion.tiaohouPriority` 必须为 `true`。
3. `geju.patternStatus` 为"成格"时，`fusion` 中必须体现格局用神的取舍。
4. `wangShuai.strengthVerdict` 与 `fiveElements[].role` 中的喜忌标签必须逻辑自洽：
   - 身强时比劫不可标"喜用/用神"（从强格除外）。
   - 身弱时食伤/财星不可标"喜用/用神"（从弱/从儿格除外）。
5. `specialPattern.type` 非 null 时，必须符合从格判定红线（日主无本气根、天干无印比透出）。
6. `tongGuan.hasConflict` 为 true 时，`tongGuanShen` 不可为 null。
7. `fusion.finalYongShenReason` 必须说明该用神满足了哪几层分析。
8. `fiveElements` 必须 5 项覆盖金木水火土，role 标签必须与 `fusion.final*` 字段严格一致。
9. 同一份四柱输入多次运行本 skill，`fiveElements` 结论必须一致。
10. 调候用神速查表中的天干必须与实际推导一致——若查表结果与命局实际情况冲突（如调候用神恰为忌神），必须在 `tiaohou.note` 中说明取舍。

## 与其他 skill 的协作

```
四柱输入 (base-yaml 或手动输入)
         |
         v
  bazi-wuxing-analyzer  ← 本 skill
         |
         v
  输出: fiveElementAnalysis + fiveElements

  bazi-data-generator   ← 消费 fiveElements，基于喜忌评分
```

- **上游**：接收四柱信息（可来自 `bazi-screenshot-parser` 解析结果，或手动输入）。

- **独立使用**：可单独运行本 skill 进行五行喜忌分析，不依赖其他 skill。
